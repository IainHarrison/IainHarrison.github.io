# Iain Harrison - Portfolio Website

An interactive portfolio website built with React and TypeScript, showcasing my work as a Developer.

## 🚀 Live Site

[https://IainHarrison.github.io](https://IainHarrison.github.io)

## 📁 Project Structure

```
├── iain-harrison-portfolio/    # React TypeScript application
│   ├── src/                   # Source code
│   │   ├── components/        # React components
│   │   ├── data/             # Project and content data
│   │   ├── types/            # TypeScript type definitions
│   │   └── styles/           # CSS styles
│   ├── public/               # Static assets
│   │   └── assets/           # Images, videos, Unity build
│   └── package.json          # Dependencies and scripts
├── .github/workflows/        # GitHub Actions for deployment
└── README.md                # This file
```

## 🛠️ Development

### Local Development

```bash
cd iain-harrison-portfolio
npm install
npm start
```

### Building for Production

```bash
cd iain-harrison-portfolio
npm run build
```

## 🚀 Deployment

The site automatically deploys to GitHub Pages when you push to the main branch using GitHub Actions.

### Manual Deployment (if needed)

```bash
cd iain-harrison-portfolio
npm run deploy
```

## 🎮 Features

- **Unity WebGL Game Integration** - Interactive portfolio demo
- **Responsive Design** - Works on all devices
- **Project Showcases** - Detailed modals with project information
- **TypeScript** - Type-safe development
- **Modern React** - Hooks, components, and best practices
